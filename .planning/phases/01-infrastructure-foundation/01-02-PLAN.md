  <action>
    Create `docker-compose.yml` at the repo root with two services:

    ```yaml
    services:
      redis:
        image: redis:7-alpine
        ports:
          - "6379:6379"
        healthcheck:
          test: ["CMD", "redis-cli", "ping"]
          interval: 5s
          timeout: 3s
          retries: 5

      celery_worker:
        build:
          context: ./celery_worker
          dockerfile: Dockerfile
        command: celery -A celery_worker.celery_app worker --loglevel=info --concurrency=2
        environment:
          - REDIS_URL=redis://redis:6379/0
          - SUPABASE_URL=${NEXT_PUBLIC_SUPABASE_URL}
          - SUPABASE_SERVICE_ROLE_KEY=${SUPABASE_SERVICE_ROLE_KEY}
        depends_on:
          redis:
            condition: service_healthy
        volumes:
          - ./celery_worker:/app
    ```

    Key decisions:
    - Redis port 6379 mapped to host for local Celery CLI debugging
    - Celery worker concurrency=2 (low for dev, per Claude's discretion)
    - SUPABASE_URL and SUPABASE_SERVICE_ROLE_KEY passed through from host .env.local for future Phase 2 DB writes
    - Volume mount for hot-reload during development
    - Redis healthcheck ensures worker waits for Redis before starting
  </action>
