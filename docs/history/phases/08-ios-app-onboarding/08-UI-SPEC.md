## Spacing Scale

Declared values (multiples of 4, logical pixels / iOS points):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline icon-to-label padding |
| sm | 8px | Chip internal padding, tag spacing |
| md | 16px | Default horizontal screen padding, card internal padding, inter-card gap |
| lg | 24px | Section vertical spacing, card grid gap |
| xl | 32px | Onboarding screen vertical rhythm between blocks |
| 2xl | 48px | Onboarding screen top safe-area clearance |
| 3xl | 64px | Bottom sheet peek height clearance |

**Exceptions:**
- Touch targets: minimum 44px height/width for all interactive elements (iOS HIG requirement). Applied to: QuickAccessBar icons, card action buttons (Done/Snooze/More), mic button, toggle, PIN cells.
- Zone 1 — QuickAccessBar: fixed height 56px (icon 24px + 16px padding top/bottom)
- Zone 2 — LoadStatusBar: fixed height 44px (exactly the minimum touch height — tapping expands breakdown)
- Zone 4 — ChatBar: fixed height 64px (icon 24px + 20px padding top/bottom + safe area bottom)
- 6-digit PIN cells: 48px × 56px per cell with 8px gaps
- Bottom sheet snap points: 0% (collapsed), 100% (full screen)

**Source:** CONTEXT.md §4-Zone Dashboard Layout; RESEARCH.md Pattern 4; iOS HIG defaults

## Interaction Contract

### Onboarding Wizard

- **Navigation:** Stack push forward only. `gestureEnabled: false` on all onboarding screens — no back swipe after PIN verification.
- **Progress bar:** Visible on screens 2–7. Screen 1 (Welcome) has no progress bar.
- **Advance condition:** Each step validates its required input before allowing forward navigation. CTA button is disabled (opacity 0.4) until validation passes.
- **Google OAuth step (Step 5):** Two CTAs — primary "Connect Google" (accent) + secondary "Skip for now →" (body weight, no background, accent text color). Skip navigates forward immediately.
- **TCPA toggle:** Default OFF. "Confirm" CTA is enabled regardless of toggle state — user may choose not to consent. If OFF, `has_alert_consent: false` is written (not missing, explicitly false).
- **Canvas URL validation:** Client-side regex checks for `webcal://` or `https://` pattern before sending. On tap "Validate": button becomes spinner (10s timeout). Success: checkmark + green border + "Looks good, continue →" CTA becomes enabled. Error: red border + specific message (see copywriting).

### 4-Zone Home Screen

**Primary focal point:** Zone 2 (LoadStatusBar). Its full-width color fill (green / yellow / red) is the first element communicating the day's urgency. All other zones are subordinate to this signal.

- **Zone 1 — QuickAccessBar:** Three icons with declared accessibilityLabel values:
  - To-Do icon (checkmark.circle): `accessibilityLabel="To-Do"`
  - Calendar icon (calendar): `accessibilityLabel="Calendar"`
  - Notifications icon (bell): `accessibilityLabel="Notifications"`
  - Icon size 24px. Touch target 44px × 44px. Tap navigates to corresponding detail stack screen.
- **Zone 2 — LoadStatusBar:** Full-width color fill bar. Tap toggles an inline expanded breakdown view (slides down, pushes Zone 3). Breakdown shows: deadline count, course list, heaviest weight item.
- **Zone 3 — Card Grid:** `DraggableFlatList` with 16px horizontal padding, 16px inter-card gap.
  - **Tap card:** Expands inline. Three action buttons revealed: "Done" (checkmark, accent), "Snooze" (clock, neutral), "More" (ellipsis, neutral). Tap again to collapse.
  - **Long-press card:** Enters drag mode. Card lifts (shadow + 4px scale up). Drag handle appears on right. Haptic feedback on lift and drop.
  - **Swipe left card:** Reveals "Hide" action (red background, white label). Swipe to 50% threshold → auto-complete hide. Removed from grid immediately; accessible in Preferences to restore.
- **Zone 4 — ChatBar:** Fixed bottom bar, 64px tall + safe area bottom inset. Shows last Aria message preview (truncated to 1 line). Right side: mic button (44px touch target). Tap anywhere on bar → slides up bottom sheet to full-screen.
- **Bottom Sheet (Chat):** Snap points: 0 (collapsed) and `SCREEN_HEIGHT` (full). Backdrop dims screen. Swipe down collapses.

### Voice Input

- **Tap mic:** Requests `SFSpeechRecognizer` permission on first use (system alert). On grant: begin recording. Mic icon transforms to waveform animation (accent color).
- **Tap mic again:** Stop recording. State transitions to "transcribing" (spinner). On result: text appears in input field, send immediately (no manual send required for voice).
- **Permission denied:** Mic icon shows warning overlay. Tapping shows inline message: "Microphone access required. Enable in Settings."
- **Partial results:** Not displayed in UI — only final result populates input (continuous: false).

### Card Skeleton (Loading State)

- Skeleton shimmer: animated gradient sweep from secondary to `#E5E5EA` (light) / `#38383A` (dark).
- Skeleton card dimensions: match collapsed card height (72px).
- Show 3 skeleton cards on initial load.
- Skeleton for ChatBar preview: single line, 60% width.

**Source:** CONTEXT.md §Card Behavior, §In-App Chat, §Specific Ideas; RESEARCH.md Patterns 3, 4, 5

## Screen-by-Screen Interaction Summary

| Screen | Route | Key Interactions | States |
|--------|-------|-----------------|--------|
| Welcome | `(onboarding)/welcome` | Tap "Get started" → push phone | default |
| Phone | `(onboarding)/phone` | Phone number input + country code; "Send verification code" → push verify | empty, typing, invalid, sending |
| Verify PIN | `(onboarding)/verify` | 6 cells auto-advance; last digit → auto-push canvas | empty, filling, error, resend |
| Canvas URL | `(onboarding)/canvas` | Paste URL; "Validate" → spinner → success/error; "Continue" enabled on success | empty, typing, validating, error, valid |
| Google OAuth | `(onboarding)/google` | "Connect Google" → expo-auth-session popup; Skip → push tcpa | default, loading, error, skipped |
| TCPA | `(onboarding)/tcpa` | Toggle (default OFF); "Confirm" → write to Supabase → push preview | toggle off, toggle on, saving |
| Preview | `(onboarding)/preview` | Scrollable briefing text; "Enter Aria" → replace stack with (home) | loading, populated |
| Home | `(home)/index` | Zone 1 icons, Zone 2 tap-expand, Zone 3 drag/swipe/tap, Zone 4 chat open | loading, populated, drag mode, chat open |
| Preferences | `(home)/preferences` | Quiet hours, accent color picker (6 swatches), integration connect/disconnect, hidden cards restore | default |
